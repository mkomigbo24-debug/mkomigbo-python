CH FALLACY PROOF - CUỌ vs CHUỌ (Diacritics Emphasis)

WordSpellingIPASound BreakMeaning
CUỌc + ụ + ọ/kʷɔ/c /k/ + ụ labialization /ʷ/ + ọ /ɔ/cuọ ala - mould soil
CHUỌch + ụ + ọ/tʃʷɔ/c /k/ + h aspiration /ʰ/ + ụ /ʷ/ + ọ /ɔ/chuọ - wash (standard collapsed)
GUỌg + ụ + ọ/gʷɔ/g /g/ + ụ /ʷ/ + ọ /ɔ/guọ ofe - stir soup
GHUỌgh + ụ + ọ/ɣʷɔ/gh /ɣ/ + ụ /ʷ/ + ọ /ɔ/missing proof

Proof: CUỌ has NO h! CHUỌ = C + H + Ụ + Ọ. Therefore CH = C+H, NOT single letter! Ụ = /ʷ/ labialization, not vowel! All vowels with dot: ị ọ ụ ṅ - each dot marks distinct phoneme!

IPA Sound: CUỌ /kʷɔ/ = lips round FIRST then release k like "quick". CHUỌ /tʃʷɔ/ = ch like "cheese" + round lips.

CH FALLACY PROOF - Core Thesis

Standard says ch is a letter. FALSE! Proof: cuo (mould soil) - the u in cuo is labialization /ʷ/ on consonant, not vowel. Therefore ch = c + h (aspiration), NOT digraph!
